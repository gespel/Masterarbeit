# Huginn
![image](images/huginn-logo-dark@2x.png)
Huginn is a system for intrusion detection and monitoring. It uses the FlexIO framework from DOCA to facilitate the processing of network packets on the DPA on the BlueField-3.

## Features
- Flow-based real-time network traffic monitoring and analysis
- Intrusion detection and alerting for suspicious network activity
- Support for multiple network protocols and packet types

## Getting Started
To get started with Huginn, follow these steps:
1. Clone the repository:
   ```bash
   git clone https://github.com/gespel/Masterarbeit.git
    ```
2. Navigate to the Huginn directory:
    ```bash
    cd Masterarbeit/huginn
    ```
3. Build the project using the provided build scripts or your preferred build system. 
   ```bash
    make
    ```
4. Execute the Huginn application on the BlueField-3 ARM-Host to start monitoring network traffic.
